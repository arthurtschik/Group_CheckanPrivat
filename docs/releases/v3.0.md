Repository. Für dich ändert sich fast nichts.

## ✨ Neu

### Neuer Ort für Downloads und Updates
- Die App sucht Updates ab jetzt nur noch bei
  [arthurtschik/Group_Checkan](https://github.com/arthurtschik/Group_Checkan). Dort gibt es nur noch die

**Wichtig:** Bitte dieses Update installieren. Ältere Versionen finden künftige Updates nicht mehr von selbst.
